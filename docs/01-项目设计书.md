## 1. 一句话

**说一句原理，生成一段可单步、可调参、可导出的算法动画。**

面向计算机 / 理工科学生，把「快速排序怎么跑」「TCP 三次握手长什么样」这类抽象过程，从一段文字变成可交互、可回溯、可带走的分步动画。

- 中文名：算法视界
- 英文名：AlgoViz Studio
- Slogan：把算法讲成看得见的过程。

## 2. 为什么是它（对齐评分表）

| 评分维度 | 权重 | 本项目的证据 |
|---|---|---|
| 过程可复现性与演进链路 | 25% | 场景是纯 JSON（DSL），可导出/导入/分享；同一 Prompt + 参数可重放；Git 细粒度提交；`docs/prompts/` 留存完整 Prompt 链；内置引擎结果确定（固定 seed） |
| 解题有效性与实用价值 | 25% | 真实场景：复习、作业、课堂演示；「理解 → 调参 → 导出笔记」闭环，导出物可直接交作业/进笔记 |
| 方法创新性与意图控制 | 20% | 自然语言 → 结构化 Scene DSL；校验-修复闭环；规则路由 + 内置引擎 + AI 兜长尾的双轨生成；布局由渲染器确定性计算 |
| 工程质量与架构设计 | 15% | TS strict + Zod 双重校验；无 `eval`、不执行 AI 代码；Vitest 覆盖引擎与校验器；无后端、无账号体系、攻击面小 |
| 用户体验与产品精细度 | 15% | 流式生成状态（阶段 + token 计数）、单步/回溯/倍速、键盘操作、讲义双页版式（纸面/钴蓝/朱砂）、导出进度可视化 |

差异化：**不是「固定题库的算法可视化网站」**，而是「自然语言驱动的可视化生成器」——长尾知识点也能生成；同时保留内置确定性引擎，保证常用场景秒开、参数实时联动。

## 3. 用户与场景

| 角色 | 场景 | 关键诉求 |
|---|---|---|
| 大二学生 | 数据结构课跟不上，想看懂快排的指针怎么动 | 分步、慢放、能回退 |
| 考研党 | 复习图算法，想对比 BFS / Dijkstra | 调参、复杂度、讲解 |
| 助教 / 老师 | 做 5 分钟课堂演示 | 视觉清晰、能导出 GIF |
| 自学者 | 看 TCP 握手文字没感觉 | 一句话生成、能看懂时序 |

典型任务流：输入一句话 → 生成 → 逐帧看 → 拖参数对比 → 导出 GIF / 讲稿 → 存进历史。

## 4. 范围（MVP，明确砍需求）

### 4.1 必须做（P0）

1. **首页 = 双页封面**：左页书名/一句话输入/示例目录，右页默认「快速排序」图版；没有侧栏。
2. **双页主界面**：左页讲义（标题、正文、公式、伪代码、参数注记），右页图版（画布、图注、标尺、页码），中缝分隔。
3. **四种图版**：数组、二叉树、图、时序（协议/消息）。
4. **四个内置确定性引擎**（无网络也能演示）：
   - 排序：冒泡 / 快速 / 归并（数组图版）
   - 二叉树：层序 / 前序 / 中序（树图版）
   - 图：BFS / Dijkstra（节点图版）
   - 协议：TCP 三次握手 / 四次挥手（时序图版，可开丢包）
5. **规则路由**：Prompt 命中关键词（快排 / 二叉树 / 握手…）直接走内置引擎，0 延迟；未命中走 AI。
6. **AI 生成**：任意主题 → Scene DSL；流式状态；Zod + 业务校验；失败自动修复 ≤2 轮；最终失败给降级提示。
7. **标尺时间轴**：右页底部 38 格刻度 + 朱砂当前帧；点击/拖拽跳帧；播放 / 暂停 / 单步 / 倍速 / 键盘（空格、←、→、Home、End）。
8. **讲义联动**：当前步高亮伪代码行、正文对应段落、复杂度数字；右页图注只留一句「当前步」。
9. **参数注记**：左页「参数」表（n / pivot / 转场 / 速度）；内置场景即时重算；AI 场景重新生成（带缓存）。
10. **导出**：页眉「导出」菜单 —— 当前帧 PNG、全流程 GIF、讲稿 Markdown、教学卡片 PNG（html2canvas）。
11. **历史与分享**：左页页脚「往期讲义」抽屉；localStorage 最近 20 个场景；导出/导入 JSON；URL hash 分享（lz-string 压缩）。
12. **设置**：模型选择、演示模式、连接状态；Key 不落前端（走 dev/preview 代理）。
13. **响应式**：≥980 双页；<980 单页堆叠（**图版在前、讲义在后**），功能不隐藏。

### 4.2 明确不做（P1 / 砍掉）

- 用户账号、云同步、后端数据库；
- 多人协作、评论；
- 深色三栏 Dashboard 主界面（已否决，见 D6）、卡片式面板堆叠；
- 执行任何 AI 生成的代码（只消费 JSON）；
- 3D / WebGL 渲染（Canvas2D 足够，且导出稳定）；
- 移动端精细适配（保证能看能用，不做像素级）；
- 内置视频录制（用系统录屏 + 剪辑）。

理由：6 天窗口 + 评分权重。功能越少越稳，演示链路越短越好。

## 5. 关键设计决策

### D1. AI 只产出 JSON（Scene DSL），不产出可执行代码
- 安全：不 `eval`、不 `new Function`，杜绝「AI 代码打穿页面」。
- 可控：Schema 约束 + 校验 + 修复，输出可被程序理解。
- 可复现：JSON 可存档、可分享、可 diff，评委能一键重放。
- 可编辑：Monaco 里改 JSON 立即重绘，人机协作闭环。

### D2. 布局由渲染器确定性计算，LLM 只给「拓扑 + 顺序」
- LLM 不擅长坐标，容易重叠/出界；树/图坐标由渲染器按层序/环形布局算。
- 同一份 JSON 在任何分辨率下都好看，导出与屏幕一致。

### D3. 双轨生成：规则路由 + 内置引擎 + AI
```
Prompt ──► 规则路由（关键词/参数正则）
              ├─ 命中 → 内置引擎（<16ms，确定性，可调参）
              └─ 未命中 → AI 生成 DSL（5–15s，长尾覆盖）
```
- 常用知识点 0 延迟、断网可演示；
- AI 只负责「内置引擎没覆盖的长尾」，成本与失败率都可控；
- 内置引擎的 DSL 同时充当 AI 的 few-shot 范例，风格统一。

### D4. 校验-修复闭环，失败降级不装死
- Zod 结构校验 + 业务规则（引用完整性、步数上限、数值范围）。
- 失败把「错误列表 + 原输出」回喂模型修复，最多 2 轮，过程写进 trace。
- 仍失败：提示原因 + 推荐相近内置场景 + 保留原始输出可复制，不静默卡死。

### D5. 无后端：本地持久化 + dev/preview 代理隐藏 Key
- 场景、历史、设置都在 localStorage；
- `/api/llm` 由 Vite 中间件代理（dev 与 preview 都生效），Key 只在 `.env.local`，不进浏览器；
- 静态部署时改用 Serverless 适配（P1，非必须）。

### D6. 视觉方向：讲义双页（The Spread）
- 四个方向的界面评审后选定：**左页讲解、右页图版、中缝装订、页码/脚注**。
- 理由：算法讲解天然是「左文右图」的阅读关系；双页把「讲解」和「演示」放在同一视线里，而且与常见的深色 Dashboard 一眼区分。
- 约束：不做侧栏、卡片、发光；视觉靠字号、栏线、纸色与图版网格；所有操作收进页眉、页脚和页边。
- 参照：`mockups/concept-spread.png`（视觉基线），`mockups/concept-spread.html`（可改）。

## 6. 功能规格

### 6.1 首页（合上的讲义）
- 摊开的两页：左页书名 / 一句话 / 示例目录，右页默认「快速排序」图版。
- 输入框在左页标题下方，像在书页上写批注；示例以「目录条目」呈现（内置场景 + 一个 AI 示例），不做胶囊。
- 视觉：纸色、细线、页码；没有卡片、阴影和发光。

### 6.2 生成器
- 输入：左页「问一句」横线输入，Enter 生成、Shift+Enter 换行，≤200 字。
- 状态机：`routing → streaming → validating → repairing → done / error`；状态只出现在页眉右侧的小字与计数，不弹窗。
- 生成中可取消；结果在右页图版「落墨」，左页正文与公式同步替换。
- 来源标注：`本地引擎` / `AI 生成` / `AI 修复后`，页眉小字。

### 6.3 图版与标尺
- 右页为图版（版心约 684×560，高度随视口伸展，保证图注/标尺在首屏），28px 蓝色网格；墨色柱、朱砂基准、蓝色斜纹比较、虚线上一帧。
- 底部标尺：38 格刻度 + 朱砂当前帧；点击/拖拽跳帧；键盘 `←/→`、`Space`、`Home/End`。
- 图号（FIG. 3.2）、图注、页码固定在版心内。

### 6.4 参数注记
- 左页「参数」表：n / pivot 策略 / 转场时长 / 速度，点线引导，像论文表格。
- 内置场景改动即重算（防抖 120ms）；AI 场景触发重新生成（命中缓存 <50ms）。
- 参数变化同步更新图版与正文里的复杂度数字。

### 6.5 讲解（左页正文）
- 左页固定结构：章节号、标题、导语、双栏正文、公式、伪代码（当前行高亮）、事实表、边注。
- 右页图注下只保留「当前步」一句，避免左右重复。
- 生成 trace 收进页眉「校验」小抽屉，不占版心。

### 6.6 导出
入口：页眉右侧「导出」文字菜单，不占版心。

| 产物 | 规格 | 实现 |
|---|---|---|
| 当前帧 PNG | 图版 2×（1368×1120） | `canvas.toBlob` |
| 全流程 GIF | 960×540，8fps，≤15MB，带进度 | `gif.js` + worker |
| 讲稿 Markdown | 标题/摘要/复杂度/公式/伪代码/步骤表/参数/Prompt | 字符串模板 + 下载 |
| 教学卡片 PNG | 标题 + 3 张关键帧 + 复杂度 + 公式，2× | `html2canvas` 截取隐藏卡片 |
| 场景 JSON | 完整 DSL | 下载 / 复制 |

失败降级：GIF 失败（worker 不可用/超时）提示并给「降低分辨率重试」与「导出 PNG 帧序列」入口。

### 6.7 历史与分享
- localStorage：`algoviz:scenes:v1`，最多 20 条，含标题、摘要、layout、时间、来源。
- 导入：拖入 JSON 或粘贴。
- 分享：`#s=<lz-string 压缩>`；打开时解压并载入，不请求服务端。
- 版本字段 `version: 1`，未来迁移用。

### 6.8 设置与演示模式
- 模型预设：DeepSeek / Qwen / GLM / 自定义 OpenAI 兼容端点。
- 演示模式：无 Key 时只跑内置引擎 + 缓存场景，UI 明确提示。
- 连接检测：设置页「测试连接」按钮，20s 超时，显示可用模型。

## 7. 交互与视觉（讲义双页）

### 7.1 版式
- 双页：左页 46%（讲解），右页 54%（图版），中缝 1px + 两侧纸面阴影；页眉细线，页脚页码。
- 页眉：字标、章号、页码；页脚：图号/帧号/快捷键；不设全局侧栏。
- 间距：页边距 56px，栏距 30px，图版内边距 24px；所有元素对齐到 8px 基线。

### 7.2 色彩（纸 / 墨 / 钴蓝 / 朱砂）
- 纸 `#F6F3EA`，纸二 `#FBF8F1`，墨 `#151515`，次墨 `#6D6658`，线 `#D8D0BF`。
- 钴蓝 `#1B4DFF`：结构色（章节号、公式、比较高亮、当前帧）。
- 朱砂 `#E4572E`：语义色（基准、警告），全页占比 < 8%。
- 不用渐变、不用发光；层次靠字号、栏线、留白和纸色差。

### 7.3 字体
- 标题/正文：Noto Serif SC（回退 STZhongsong / SimSun）。
- 界面/表格：DengXian（回退 Microsoft YaHei）。
- 标签/数字：Cascadia Mono；字标：Bodoni MT。
- 字号阶：标题 86px / 导语 15px / 正文 12.5px / 注 10px / 标签 8.5px；行高 1.9–2.0。

### 7.4 动效（“翻页感”，入场 480ms、其余 ≤ 320ms）
- 入场：页眉线自左绘出、标题上移 10px、左页段落淡入（480ms）。
- 换步：图版内柱体高度/位置 tween 240ms；比较柱用蓝色斜纹从左「刷」出；基准归位时朱砂圆环 240ms 一次性。
- 联动：伪代码当前行底色 160ms 淡入；正文对应段落左侧蓝线 200ms 展开。
- 标尺：当前刻度抬起 2px、朱砂块平移 180ms；拖拽即时跟手。
- 禁止：视差、粒子、持续呼吸、弹窗式飞入；`prefers-reduced-motion` 时全部改为 120ms 淡入。

### 7.5 三态与可访问性
- 空态：合上的讲义（左页书名 + 示例目录，右页空白图版水印）。
- 加载：图版位置显示「正在落墨」骨架线，不遮挡左页。
- 错误：左页顶部一条朱砂提示 + 重试，保留原文。
- 焦点环 2px 钴蓝；图版提供文字版步骤列表（屏幕阅读器）；对比度 ≥ 4.5:1。

## 9. Scene DSL（核心）

### 9.1 类型（简化）

```ts
type Layout = 'array' | 'tree' | 'graph' | 'sequence';

interface Scene {
  version: 1;
  id: string;
  title: string;
  subtitle?: string;
  layout: Layout;
  category: 'sort' | 'search' | 'tree' | 'graph' | 'network' | 'other';
  summary: string;                 // 一句话原理
  bullets?: string[];              // ≤5 条要点
  complexity?: { time: string; space: string; note?: string };
  formula?: string;                // LaTeX
  pseudocode?: string;
  params: ParamSpec[];
  steps: SceneStep[];              // 1..120
  source: 'builtin' | 'ai';
  prompt?: string;
  model?: string;
  createdAt: string;
}

interface SceneStep {
  title: string;                   // ≤24 字
  caption: string;                 // ≤80 字
  codeLine?: number;
  durationMs?: number;             // 默认 900
  state: ArrayState | TreeState | GraphState | SequenceState;
}
```

四种 state：

```ts
interface ArrayState {
  kind: 'array';
  values: number[];                          // ≤64
  marks?: { index: number; tone: 'compare'|'swap'|'active'|'done'|'pivot' }[];
  pointers?: { label: string; index: number }[];   // i / j / pivot
  ranges?: { from: number; to: number; tone: 'active'|'sorted'|'pivot' }[];
  badges?: string[];                          // 如 "已排序 5/10"
}

interface TreeState {
  kind: 'tree';
  nodes: { id: string; label: string; parent: string | null; side?: 'L'|'R' }[]; // ≤31
  order?: string[];                           // 已访问顺序
  current?: string;
  frontier?: string[];                        // 队列 / 栈
  marks?: { id: string; tone: ... }[];
}

interface GraphState {
  kind: 'graph';
  nodes: { id: string; label: string }[];     // ≤20，坐标由渲染器计算
  edges: { from: string; to: string; weight?: number; directed?: boolean }[];
  visited?: string[];
  frontier?: string[];
  path?: string[];
  marks?: { id: string; tone: ... }[];
}

interface SequenceState {
  kind: 'sequence';
  lanes: { id: string; label: string }[];     // 如 Client / Server
  messages: { id: string; from: string; to: string; label: string;
              tone?: 'syn'|'ack'|'data'|'fin'; lost?: boolean }[]; // ≤12
  active?: string;
  notes?: { lane: string; text: string }[];
}
```

{
  "version": 1, "id": "qs-8", "title": "快速排序", "layout": "array",

### 9.3 约束与校验规则

- `steps.length ∈ [1, 120]`；每步 `title` 非空、`caption` ≤ 80 字。
- 数组：`values.length ∈ [2, 64]`，全部为有限数；`marks.index` 在范围内。
- 树：节点 ≤ 31；`parent` 必须存在或为 `null`；禁止环；**根唯一**；`side` 与父节点匹配。
- 图：节点 ≤ 20；边端点必须存在；Dijkstra 场景权重 > 0；无自环。
- 时序：`lanes ≥ 2`；消息端点在 lanes 中；消息 ≤ 12 条。
- 数值：参数默认值落在 `[min, max]`；`durationMs ∈ [200, 5000]`。
- 文本：去除控制字符；禁止 `<script>` 等注入模板（React 默认转义，仍做长度限制）。
- 所有失败返回结构化错误列表（`path` + `message`），供修复提示使用。

## 10. AI 生成流水线

1. **路由**：先本地关键词/正则（排序、树、图、握手、查找…），命中即返回内置场景。
2. **组 Prompt**：
   - System：角色（计算机教学动画导演）、必须遵守 DSL、只输出 JSON、规模上限、布局选择规则、两个 few-shot（快排 + TCP）。
   - User：原始需求 + 解析出的参数（数量、类型）+ 输出要求。
3. **请求**：`/api/chat`，`stream: true`，`temperature: 0.2`，`max_tokens: 4000`，`response_format: json_object`（不支持的供应商自动降级）。
4. **流式展示**：按 token 计数 + 阶段文案（解析意图 → 生成结构 → 校验 → 编排动画），可取消。
5. **解析**：剥离 ```json 围栏 → `JSON.parse` → Zod → 业务规则。
6. **修复**：把 `issues` 转成「错误清单」追加到对话，≤2 轮；每轮记录 trace。
7. **缓存**：`hash(prompt + model + params)` → localStorage；命中直接返回（<50ms）。
8. **降级**：失败时展示错误摘要、推荐 3 个相近内置场景、保留原始输出可复制。
9. **成本控制**：默认小规模（数组 ≤12、树 ≤15、图 ≤10、消息 ≤8），整场演示 3–5 次生成，成本约 ¥0.1–1。

## 11. 渲染器

| 图版 | 绘制 | 动画 |
|---|---|---|
| 数组 | 墨色柱 + 下标 + 朱砂基准 + 蓝色斜纹比较 | 高度 tween 240ms；比较从左刷出；基准圆环 240ms |
| 树 | 纸面层序布局，细线连边 | 新节点墨迹淡入；路径蓝线描边 |
| 图 | 环形布局 + 节点标签 | 边逐段高亮；当前节点朱砂圈 |
| 时序 | 泳道 + 箭头 + 消息标签 | 箭头沿 x 生长；丢包虚线 |

统一：图版高度随视口伸展（min 220px），网格 28px；`draw(ctx, state, progress)`；导出按 1368×1120（2×）重绘，纸色/线宽与屏幕一致。

## 12. 导出实现

- **PNG**：舞台 canvas `toBlob`，可选 2×（2560×1440）。
- **GIF**：`gif.js`，worker 由 `public/gif.worker.js` 提供（构建时从依赖复制，仓库内置，保证离线可用）；逐帧渲染每步的中间态（每步 1–2 帧），8fps，尺寸 960×540，质量 10；进度回调更新按钮文案。
- **Markdown**：模板生成，含 front-matter（title/layout/model/date）、参数表、复杂度、公式 LaTeX、伪代码、步骤表（序号/标题/讲解）、原始 Prompt。
- **教学卡片**：隐藏 DOM 卡片（标题 + 3 帧缩略图 + 复杂度 + 公式 + 二维码占位），`html2canvas` 2× 导出。
- **JSON**：`Blob` 下载 + 复制到剪贴板。
- 全部导出带 `scene.title` 文件名（中文安全处理）。

## 14. 质量保障

- **类型**：`strict: true`，`noUncheckedIndexedAccess`，禁止 `any`（除第三方边界）。
- **单测**（Vitest）：
  - 快排/冒泡/归并：终态有序、步骤数 > 0、每步状态合法；
  - 树遍历：层序/前序/中序顺序正确；
  - Dijkstra：最短路长度正确；
  - TCP：握手 3 条消息、挥手 4 条；
  - 校验器：坏 JSON、越界索引、环树、悬空边全部拒绝。
- **错误边界**：渲染异常不白屏，显示「场景数据异常」+ 重试。
- **性能预算**：首屏 JS ≤ 350KB gzip（不含 Monaco）；Monaco/GIF/html2canvas 全部动态 `import()`；画布单 rAF；切步 < 16ms。
- **兼容**：Chrome/Edge 最新两个大版本（比赛演示环境）。
