注 NOTES
  1. 1
    基准（pivot）

    取末元素 7。分区结束后它落在最终位置，左边都 ≤ 7，右边都 > 7。

  2. 2
    指针 i

    已扫描区里最后一个 ≤ 基准的位置；下一个比 7 小的元素会与 i+1 交换。

  3. 3
    区间划分

    左区 [0..5] 与右区 [7..9] 递归处理；单元素或空区间直接返回。

稳定性否

伪代码 CODE
1function quickSort(a, l, r):
2  if l >= r return
3  p = partition(a, l, r)
4   swap(a[p], a[r])   // 基准归位
5  quickSort(a, l, p - 1)
6  quickSort(a, p + 1, r)
