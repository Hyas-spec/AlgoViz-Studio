## 二、作品简介（三种长度，按表单字数限制选）

### 一句话（≤30 字）

> 说一句原理，生成一段可单步、可调参、可复现的算法动画。

### 100 字版

> AlgoViz 是一个面向计算机 / 理工科学生的算法可视化工作台：输入一句自然语言，生成一页「左讲义、右图版」的算法讲义。内置 10 个确定性场景，长尾主题由大模型生成受约束的 Scene DSL，经三层校验与最多 3 轮自动修复后上屏，可单步、可调参、可回放。

### 300 字版

> AlgoViz（算法视界）解决的是「算法过程看不见」的问题。学生看静态图知道快排要分区，却不知道指针每一步怎么移动；看伪代码能背 Dijkstra 的松弛，却对不上「待确定集合」的变化。
>
> 作品把一句自然语言描述转换成结构化的 Scene DSL，再由四个确定性渲染器画成可单步、可回退、可调参的算法讲义。系统有两条生成路径：10 个常用场景走内置引擎，零延迟、断网可用；长尾主题走大模型，流式生成 JSON，经 Zod 结构校验、业务规则与教学质量线检查，不合格自动回喂修复，最多 3 轮。
>
> 关键取舍是「模型不碰坐标、不执行代码」：模型只负责讲什么，渲染器负责怎么画，中间层负责不能乱画。这让 AI 的失败可解释、可修复，也让同一份 JSON 在任何分辨率下画出同一个过程。当前已实现 10 个场景、4 类图版、AI 生成与修复、AI 历史与直接讲解，92 个单元测试全部通过。

## 三、项目亮点（表单若有「亮点」栏，任选 3–5 条）

1. **不是套壳聊天**：模型只输出受 Schema 约束的 Scene DSL，不生成坐标、不执行代码；Zod + 业务规则 + 质量线三层校验，失败结构化回喂，最多 3 轮自动修复。
2. **双轨生成，课堂不断线**：10 个内置场景由确定性引擎生成，断网、无 Key 也能演示；AI 只负责长尾主题，成本与失败率可控。
3. **讲义双页的视觉语言**：左文右图、中缝装订、纸 / 墨 / 钴蓝 / 朱砂四色，与常见的深色 Dashboard 一眼区分；四档投影字号让教室后排也看得清。
4. **教学过程可核对**：点伪代码跳帧、拖标尺、过程量、图例、只读 JSON 抽屉，学生不只看动画，还能核对「第 12 帧到底改了什么」。
5. **可复现性写进产品**：内置场景同参数同结果；URL 参数即状态；AI 场景存历史、`#ai=<id>` 刷新恢复；JSON 可快照、可 diff。
6. **工程证据完整**：仓库 60 余个细粒度提交、4 条 Prompt 链（含对话截图与失败修复记录）、92 个单元测试、10 分钟复现指南。

## 四、AI 技术落地使用情况（表单若有此栏，200 字版）

> 开发侧：使用 DeepSeek Harness 作为 AI 编程代理，从界面选型、脚手架、Scene DSL、三排序与树 / 图 / 时序引擎，到 AI 生成闭环、历史与讲解、文档与视频脚本，按「提案 → 实现 → 验收 → 提交」逐轮推进；4 条 Prompt 链完整保留了提问、AI 建议、失败定位与修复指令。
>
> 产品侧：内置 DeepSeek-Chat 生成能力，经服务端 `/api/llm` 以 SSE 流式调用；输出经三层校验与最多 3 轮修复后上屏，失败降级不污染当前页面；另有「直接讲解」模式把概念问题转成结构化问答卡。
>
> 质量侧：92 个单元测试覆盖引擎、校验、AI 解析 / 修复 / 质量线与历史；10 条 AI Prompt 回归 9/10 上屏，红黑树与插入排序的修复过程有截图与 commit 可查。

## 五、关键技术（表单若有「关键技术」栏）

- React 19 + TypeScript strict + Vite 8；
- Scene DSL v2：array / tree / graph / sequence 四态判别联合；
- 三层校验：Zod Schema → 业务规则（根唯一、无环、悬空边、泳道引用）→ 教学质量线（帧数、元素数、末帧 doneAll、codeLine 范围）；
- 校验-修复闭环：结构化 issues 回喂，最多 3 轮；
- 四个 Canvas 2D 确定性渲染器（坐标由渲染器计算，模型只给拓扑与顺序）；
- Vite middleware `/api/llm`：SSE 透传，Key 只在 Node 侧；
- KaTeX 公式、只读 JSON 抽屉、localStorage AI 历史 + `#ai=` 深链；
- Vitest 92 例、`tsc --noEmit`、`vite build` 674 KB raw / 207 KB gzip。
