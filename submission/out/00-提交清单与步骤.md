## 二、提交前的 6 项核对（10 分钟）

- [ ] **仓库公开**：浏览器无痕打开 <https://github.com/Hyas-spec/AlgoViz-Studio>，能看到代码与 `docs/prompts/`（不需要登录）。
- [ ] **提交历史**：仓库首页 Commits 能看到 60 多次按功能拆分的提交，不是一次 `initial commit`。
- [ ] **README 可复现**：README 里有 `npm ci`、`.env.local` 模板、`npm run dev`、`npm test` 与常见问题。
- [ ] **视频规格**：6 分 29 秒（在 5–8 分钟内）、1920×1080、有声音；第 3:00–5:00 是 AI 输入 Prompt → 流式生成 → 上屏的连续录屏（≥2 分钟）。
- [ ] **技术文档页数**：PDF 共 26 页（≤30 页），含意图控制、架构设计、可复现性三章重点。
- [ ] **作品介绍文档**：PDF 共 12 页，按表单 6 的 7 项要求逐条对应（项目详情与使用方式、亮点、AI 落地、关键技术、图片、发表/获奖、是否基于其他项目）。

## 三、一步一步提交（按顺序做）

### 第 1 步：把材料包上传网盘（对应字段 5）

1. 打开本目录上一级的 `AlgoViz-提交材料-2026-11-18.zip`（约 19 MB，已打好包）。
2. 上传到 **百度网盘 / 夸克网盘 / 阿里云盘** 任一（建议百度网盘，最通用）。
3. 右键文件 → **分享** → 选择 **永久有效**（不要选 7 天）→ 如有「提取码」选项，选 **有提取码**（如 `aviz`）。
4. 复制分享链接与提取码，先粘到记事本，格式整理成一行：

   ```text
   链接：https://pan.baidu.com/s/1xxxxxxxx 提取码：aviz
   ```

5. **自检**：退出登录（或用无痕窗口）打开该链接，确认能看见文件、能输入提取码、能下载。

> 为什么用 zip：字段 5 只要一个链接，评委点开能看到「文档 / 源码 / 视频 / Prompt 快照」的完整结构，比散放多个链接稳。

### 第 2 步：把视频传到 B 站（对应字段 7）

> 表单明确要求：**不要提交网盘链接**，视频必须上传到 B 站、抖音等可公开访问的平台，提交 `https://...` 链接。

1. 打开 <https://member.bilibili.com/platform/upload/video/frame>，登录。
2. 上传 `05-演示视频/AlgoViz-演示视频-1080p.mp4`（6 分 29 秒，12.9 MB）。
3. 填写：
   - **标题**：`AlgoViz 算法视界｜说一句原理，生成可单步的算法动画（传智杯省赛 B 组）`
   - **分区**：知识 → 校园学习（或 科技 → 计算机技术）
   - **标签**：算法可视化、Vibe Coding、AI 编程、数据结构、传智杯
   - **简介**：一句话定位 + 仓库地址 `https://github.com/Hyas-spec/AlgoViz-Studio` + 「本视频为参赛作品演示，含 2 分钟 AI 协同生成过程录屏」。
4. 版权/转载：选 **自制**；可见范围：**公开**（不要选仅自己可见/粉丝可见）。
5. 提交审核，等待通过（通常几分钟到几小时）。
6. 审核通过后，复制视频页地址，形如 `https://www.bilibili.com/video/BV1xxxxxxxxx`。
7. **自检**：退出登录或用无痕窗口打开该链接，能直接播放、不需要登录。

> 如果 B 站审核慢：抖音也可以（同样要求公开），但 B 站更适合长视频与电脑端观看，优先 B 站。

### 第 3 步：登录 WPS 表单，逐项填写

1. 打开比赛表单链接（就是截图里这个「WPS 表单」页面）。
2. 点顶部蓝色 **登录**（表单要求登录才能填写），用你的 WPS 账号登录。
3. 字段 1–4（作品名称、作者/团队、学校、组别等，若表单有）：照 `00-表单填写文案.md` 复制。
4. **字段 5 · 完整作品文件链接**：粘贴第 1 步的「链接 + 提取码」。
5. **字段 6 · 作品介绍文档**：点「上传文件」，选 `02-作品介绍文档/AlgoViz-作品介绍文档.pdf`（12 页，约 1 MB，远小于 100 MB 上限；只传这 1 个文件）。
6. **字段 7 · 演示视频地址**：粘贴第 2 步的 B 站链接（必须是 `https://` 开头，不要带多余文字）。
7. 从头到尾检查一遍：链接能点开、文件已上传（显示文件名）、没有漏填的必填项（带 `*` 的）。
8. 点 **提交**。
9. **立刻截图**：提交成功页、表单填写完成页各截一张，存到 `提交凭证/` 文件夹，文件名带日期。

### 第 4 步：提交后 5 分钟收尾

- [ ] 重新打开表单链接，确认状态是「已提交」（若可查看）。
- [ ] 把提交成功截图、网盘链接、B 站链接、提交时间记到一处（本文件末尾「提交记录」）。
- [ ] 本地保留一份完整材料包（U 盘 / 另一块网盘各一份）。
- [ ] 若平台允许修改：截止前 24 小时再检查一次链接是否失效。

## 四、最容易翻车的 6 个点

| 风险 | 表现 | 预防 |
|---|---|---|
| 网盘链接失效 | 评委打开提示「分享已取消」 | 分享时选「永久有效」，提交前用无痕窗口自检 |
| 视频不可见 | B 站视频「仅自己可见」或还在审核 | 提交前用无痕窗口打开链接确认能播 |
| 视频超时长 | 超过 8 分钟被扣分或退回 | 当前 6:29，若换精剪版务必确认 ≤8:00 |
| PDF 超页 | 技术文档 >30 页 | 当前 26 页；若自己改内容后重新导出，先数页 |
| 上传错文件 | 字段 6 传了技术文档或 zip | 字段 6 只传 `02-AlgoViz-作品介绍文档.pdf` |
| 仓库不可见 | GitHub 变成 Private | 提交前无痕打开仓库首页确认 |
